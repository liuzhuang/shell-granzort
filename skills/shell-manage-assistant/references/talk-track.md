# ShellManage 推广口述话术（同事演示版）

## 30 秒开场

`shell-manage` 是一个命令工作台。它把项目启动、日志、SSH、常用脚本都收敛成可视化命令卡片，减少每次切目录找命令的重复劳动。

## 2 分钟演示节奏

1. **先展示结果**
   - 打开首页，点一个命令卡片，看到服务启动或终端输出。
2. **再讲配置成本**
   - 现在可以直接安装 `shell-manage-assistant` Skill。
   - 用户只要说“帮我把项目接入 shell-manage”，Skill 会引导或半自动完成配置。
3. **最后讲风险控制**
   - Skill 写入前会先校验并确认。
   - 失败可回滚，避免把配置改坏。

## 常见问答（销售/同事）

### Q1: 我需要懂 YAML 吗？

不需要。Skill 会先给引导步骤，必要时再帮你生成和修改配置。

### Q2: 新同事第一次用会不会很难？

不会。Skill 已覆盖“下载、安装、升级、配置、排障”完整流程，照着步骤走即可。

### Q3: 万一改坏了怎么办？

Skill 默认走“先预览、后确认、再写入”，并且每次都会给回滚路径。

### Q4: Cursor 和 CC 能都用吗？

可以。两端使用同一套协议，保证答疑和配置引导口径一致。

## 结束语

如果你愿意，我现在可以在 3 分钟内帮你把当前项目接进来，之后你只要点卡片就能启动服务。
