# ShellManage 下载、安装与升级

本文件是 Skill 的“安装真相源（source of truth）”。Skill 在回答下载安装问题时，先读取本文件与 `distribution-manifest.yaml`，再给用户步骤。

> 注意：当前 `distribution-manifest.yaml` 是模板示例，含占位符 URL/SHA（如 `example.com`、`REPLACE_WITH_REAL_SHA256`）。在未替换为真实分发信息前，Skill 必须中止安装/升级指引，并提示用户补充真实发布数据。

## 1. 下载决策

1. 识别用户目标：
   - 首次安装
   - 升级已有版本
   - 回退到指定版本
2. 识别环境：
   - macOS 芯片：Apple Silicon（arm64）或 Intel（x64）
   - 网络环境：可直连外网或仅可访问内网镜像
3. 识别分发通道：
   - 默认 `stable`
   - 明确要求体验新功能时使用 `beta`

## 2. 首次安装（macOS）

1. 从 `distribution-manifest.yaml` 读取对应架构安装包 URL。
2. 下载 `.dmg` 并双击挂载。
3. 将 `ShellManage.app` 拖入 `Applications`。
4. 首次启动如果被 Gatekeeper 阻止：
   - 到“系统设置 -> 隐私与安全性”选择“仍要打开”。
5. 启动后进入首页，确认可以看到默认界面。

## 3. 安装后校验

至少完成以下三项：

- 应用能正常启动，且无崩溃。
- 可以看到版本号（关于页或设置页）。
- 配置文件路径可读（或在 UI 中可打开配置编辑区域）。

## 4. 升级流程

1. 读取当前版本（用户提供或让用户在应用中查看）。
2. 对比 `distribution-manifest.yaml` 的目标通道版本。
3. 若需升级：
   - 下载新包并覆盖安装（拖到 `Applications`，系统提示替换）。
4. 升级后做最小回归：
   - 启动应用
   - 打开至少一个已有命令卡片
   - 打开配置编辑器确认无结构损坏

## 5. 回滚流程

当出现升级后不可用：

1. 从 release 历史下载上一稳定版本。
2. 覆盖安装旧版本。
3. 验证：
   - 启动正常
   - 关键命令可运行
   - 配置文件结构仍完整

## 6. 安装失败诊断分支

### A. 下载失败

- 可能原因：网络拦截、证书问题、URL 失效。
- 处理顺序：
  1. 检查 `distribution-manifest.yaml` 是否已更新。
  2. 切换到 `fallback.releasePage` 下载。
  3. 如公司网络受限，改走内网镜像地址（由发布负责人维护）。

### B. 安装失败

- 可能原因：包损坏、权限不足、磁盘空间不足。
- 处理顺序：
  1. 重新下载并校验 sha256。
  2. 确认 `Applications` 目录可写。
  3. 清理空间后重试。

### C. 启动失败

- 可能原因：安全策略阻止、系统版本不匹配、旧进程残留。
- 处理顺序：
  1. 在“隐私与安全性”放行。
  2. 完全退出旧进程后重新启动。
  3. 若仍失败，回滚上一版本并收集日志。
